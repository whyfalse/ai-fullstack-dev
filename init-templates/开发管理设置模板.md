# setting.local.json 规则说明

本项目仅在**全栈项目管理目录**根下存在一份 `setting.local.json`，记录前端、后端代码项目的路径，是三空间互引的唯一纽带（代码仓侧不创建 `setting.local.json`；开发者 Agent 统一安装于项目管理空间，以本文件定位目标仓）。

## 1. 全栈项目管理目录下的 `setting.local.json`

记录前端、后端代码项目的路径。

```json
{
    "frontend": {
        "projectPath": "D:/frontend-proj"
    },
    "backend": {
        "projectPath": "D:/backend-proj"
    }
}
```

## 2. 测试者私人配置 `tester/config.local.md`

测试者的工作文件夹为项目管理目录下的 `tester/`，其中：

- `tester/config.md`：全局测试配置（账号/工具选型/标准环境），团队共享、入库，由架构师首次架构设计时产出骨架（参照 `templates/tester-config-template.md`）。
- `tester/config.local.md`：私人测试配置（个人覆盖），**不入库**（见 `.gitignore`），由开发者个人按需创建，结构同 `config.md` 三节，只填与全局不同的项。

读取顺序：测试者先读 `tester/config.md`（基座），再读 `tester/config.local.md`（若存在，按"私人覆盖全局、未覆盖项回退全局"合并）；前后端路径仍读根 `setting.local.json`（第 1 节）。即测试者私人配置只覆盖测试专项（工具命令/环境地址/个人账号），不重复路径配置。

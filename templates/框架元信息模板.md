# framework.json 规则说明

全栈项目管理目录根下存在一个 `framework.json`，记录初始化时所用的框架元信息，入库共享，供团队追溯与版本比对使用。

## 字段说明

| 字段 | 类型 | 必填 | 说明 |
| ---- | ---- | ---- | ---- |
| `name` | string | 是 | 框架名称，固定为 `ai-fullstack-dev` |
| `version` | string | 是 | 初始化时框架模板源的版本号，取自模板源根目录 `SKILL.md` frontmatter 中的 `version` 字段 |
| `initializedAt` | string | 是 | 初始化日期，格式 `YYYY-MM-DD` |

## 结构示例

```json
{
    "name": "ai-fullstack-dev",
    "version": "1.0.0",
    "initializedAt": "2026-08-21"
}
```

## 维护说明

- 该文件由初始化流程写入，记录的是**初始化时点**的框架版本快照。
- 模板源后续升版**不会自动更新**此文件；如需同步，可重新调用 `ai-fullstack-dev` 技能并走升级流程，或人工更新 `version` 字段。
- 与模板源比对版本时，以模板源根目录 `SKILL.md` frontmatter 中的 `version` 字段为权威来源。
